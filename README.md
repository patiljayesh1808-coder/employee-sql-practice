# Employee SQL Practice

This repository contains a collection of **MySQL SQL queries** created for practicing employee database operations and solving real-world data-related requirements.

## 🛠️ Technologies Used

* MySQL
* MySQL Workbench
* SQL

## 📚 Topics Covered

* `SELECT` and `WHERE` clauses
* Salary and experience-based filtering
* `INSERT`, `UPDATE`, and `DELETE`
* `ALTER TABLE`
* Aggregate functions: `SUM()`, `MAX()`, `MIN()`, `AVG()`, `COUNT()`
* Subqueries
* Highest and lowest salary queries
* Second-highest and second-lowest salary
* Employee record analysis

## 🎯 Purpose

The main purpose of this project is to strengthen **SQL fundamentals and database query-writing skills** through practical employee management scenarios.
